    Roadmap

    Roadmap

    A snapshot of what is implemented, in progress, and planned for Upscale SDK. Planned features may change as development priorities evolve.

    See the Changelog for update history and upgrade notes.

    Shipped¶

    • Core and platforms

      • Core runtime — Saves, Input, and UI modules.
      • Support for major console and desktop platforms.
      • Build validation.
      • Base console social features — Achievements and Activities.

    • Input and glyphs

      • Keyboard and mouse input, with dedicated glyph sets.
      • Controller model detection and separate glyph sets for DualSense, DualShock 4, Xbox Controller, Switch Pro Controller, and Joy-Cons.
      • Glyph lookup directly from action definitions, including lookup for a specific device type.

    • UI and control layouts

      • Additional UI controls — ActionToggleElement, ActionScrollbarElement, and ActionScrollViewElement.
      • Visual control layouts for gamepad, keyboard, and mouse, with action labels and connector lines.
      • Horizontal and vertical control hint lists, with automatic device selection or explicit device filtering.
      • Shared action lists for device layouts, with automatic refresh when devices connect or disconnect.

    • Saves

      • Automatic save error handling on PS4 and PS5, without manual canvas wiring.
      • Editor tooling for deleting desktop save files.

    • Editor tools

      • Visual glyph layout editing in the Inspector, including device images, button anchor placement, and layout previews.

    • Cheats

      • In-game cheat code system and debug console integration.
      • Configurable cheat shortcuts for rapid testing and development.

    • Samples

      • Sample scenes for Input, Saves, UI, and Device Layouts.

    What's next¶

    • In progress

      No additional features are currently listed here. The current focus is stabilization and architectural planning.

    • Planned

      • Further improvements to the save system.
      • Improve public APIs and replace remaining placeholder API documentation.
      • Manual gamepad mapping selection for testing in the Unity Editor.
      • Localization module.

    • Under consideration

      • Multilingual documentation.
      • Refactoring and architectural cleanup.
      • Improvements to the input binding builder API.
      • Additional gamepad features, including lightbar control.

    Have a request? Open an issue on the GitHub repository and tag it roadmap.
